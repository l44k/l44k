## ⭐ Featured: BSV agent payments

**[bsv-agent-payments](https://github.com/l44k/bsv-agent-payments)**: AI agents that negotiate prices with each other and pay automatically with BSV micropayments. A buyer agent asks competing seller agents for quotes, negotiates with them in parallel, pays the cheapest one on the BSV testnet, and the seller delivers its LLM service only after verifying the payment on-chain. Built as the prototype for a bachelor's thesis.

- Agent-to-agent price negotiation with alternating offers
- Pay-before-delivery over HTTP (*402 Payment Required*)
- Each agent runs in its own Docker container
- Every task traced end to end with OpenTelemetry and Jaeger
